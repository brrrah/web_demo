# GAME-P0A Core 1v1 Combat Graybox

TypeScript, Vite, and Phaser 3 graybox for deterministic 60 Hz 1v1 combat.

## Controls

- WASD: move
- Mouse: aim
- Left click: light attack
- Right click: heavy attack; hold Shift when starting to add a short delay
- Space: directional dodge
- F: timing parry
- R: immediate round restart
- F3: debug hitboxes, states, attack/parry phases, and frame time

## Commands

```sh
npm run dev
npm test
npm run lint
npm run build
```
